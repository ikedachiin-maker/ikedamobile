# ikedamobile 完全自動システム プレゼン台本

## 1. イケダモバイルとは？

みなさん、こんにちは。
今日は「イケダモバイル」の完全自動システムについてお話しします。

まず、イケダモバイルとは何かをご説明します。

イケダモバイルは、**日本で使える格安SIMカードを提供するサービス**です。
お客様がウェブサイトからプランを選んで申し込むと、SIMカードの電話番号と予約番号がメールで届く。
お客様はそれを使ってSIMカードを有効化して、すぐに使い始められるという仕組みです。

料金プランは3つあり、1回線あたり月額3,000円〜3,600円で提供しています。

---

## 2. 以前の課題：すべてが手作業だった

これまで、申し込みが来るたびに、以下の作業を**すべて手動**でやっていました。

1. お客様の個人情報をフォームで受け取る
2. その情報を、SIMカードの管理システム（jpmob）に**1件ずつ手入力**する
3. 約1時間後に予約番号が発行されるので、それを**手動で確認**する
4. 予約番号をお客様に**1人ずつメール**で送る

お客様が増えれば増えるほど、この繰り返し作業に時間がかかる。
しかも入力ミスのリスクもある。
これが大きな課題でした。

---

## 3. 完全自動システムの全体像

そこで今回、**申し込みから予約番号の送信まで、すべてを自動化**しました。

お客様の体験はこうなります。

> 1. **ikedamobile.com** にアクセス
> 2. プランを選んで、**クレジットカードで決済**
> 3. 個人情報と**本人確認書類**をアップロード
> 4. あとは待つだけ。**自動でメールが届く**

お客様がやることはたったこれだけです。

## 4. 裏側の仕組み

では、裏側では何が起きているのか。

申し込みが完了した瞬間から、システムが自動で動き始めます。

**【ステップ1】決済と記録（即時・自動）**
お客様がカード決済をすると、Stripeから通知が飛んできます。
その瞬間に、お客様の情報がGoogleスプレッドシートに自動記録されます。
本人確認書類はGoogle Driveに自動保存されます。

**【ステップ2】SIMカード管理システムへの自動入力（毎日定時・自動）**
毎日決まった時間に、システムが自動でjpmobにログインし、
お客様の名前・生年月日・性別などを**1件ずつ正確に自動入力**します。
この部分はSeleniumというブラウザ自動操作の技術で実現しています。

**【ステップ3】予約番号の自動取得（約1時間後・自動）**
jpmobが予約番号を発行するまで約1時間かかるので、
システムが自動で待機し、発行され次第すぐに取得します。

**【ステップ4】お客様へのメール送信（自動）**
取得した予約番号・電話番号・有効期限を、
Gmail APIを使って**お客様1人ひとりに自動送信**します。
複数回線をお申し込みの場合は、1通のメールにまとめて送られます。

**【おまけ】フォーム未記入リマインダー（自動）**
もしお客様が決済後にフォームを記入し忘れていたら、
24時間後と48時間後に**自動でリマインダーメール**が送られます。

## 5. ここがすごい！3つのポイント

### ポイント1：お客様の体験がシンプル

お客様はウェブサイトで申し込んで支払うだけ。
あとは自動でメールが届きます。
**「申し込んだのに連絡が来ない」がなくなりました。**

### ポイント2：人間がやることはほぼゼロ

申し込みの受付、情報入力、予約番号の確認、メール送信。
以前はすべて手作業でしたが、今はシステムがすべてやります。

**運営者がやることは「パソコンを起動しておく」だけ。**

空いた時間を、新規顧客の獲得やサービス改善に使えるようになりました。

### ポイント3：ミスがなくなる

人間が手入力すると、名前の打ち間違い、メールの送り忘れ、
予約番号のコピーミスといったヒューマンエラーが起きます。
自動化したことで、**これらのミスがゼロ**になりました。

## 6. 技術構成（聞かれた場合の補足）

| 要素 | 技術 |
|------|------|
| ウェブサイト・API | Flask + Railway（クラウド、24時間稼働） |
| 決済 | Stripe（クレジットカード） |
| 顧客データ管理 | Google Spreadsheets |
| 書類保存 | Google Drive |
| SIM管理システム入力 | Selenium（ブラウザ自動操作） |
| メール送信 | Gmail API |
| ドメイン・DNS | Cloudflare（ikedamobile.com） |

## 7. 今後の展望

現在、SIMカード管理システムへの自動入力部分だけはMacで実行しています。
これは、jpmobというシステムにAPIがなく、ブラウザ操作でしか入力できないためです。

今後はこの部分もクラウドに移行して、
**パソコンの電源すら不要な、完全クラウド型の自動システム**を目指しています。
